# Cómo citar Garúa

Si utilizas Garúa en una investigación, tesis, artículo o informe técnico, y consideras citar el software, indica la versión utilizada. Esto permite reconocer la herramienta
y documentar cómo se obtuvieron o analizaron los datos del estudio.

## Referencia del software

Para la versión 0.31.0, utiliza esta referencia:

> Neyra, D. D. (2026). *Garúa: herramienta para consultar y analizar datos hidrometeorológicos del SENAMHI Perú* (versión 0.31.0) \[Software\]. https://github.com/danyneyra/garua

### BibTeX

```bibtex
@software{neyra_garua_2026,
  author  = {Neyra, Dany Daniel},
  title   = {Garúa: herramienta para consultar y analizar datos hidrometeorológicos del SENAMHI Perú},
  version = {0.31.0},
  year    = {2026},
  month   = oct,
  url     = {https://github.com/danyneyra/garua}
}
```

Los metadatos de citación se mantienen en
[`CITATION.cff`](https://github.com/danyneyra/garua/blob/main/CITATION.cff).
Si utilizaste otra versión, consulta el archivo de esa versión en el
[historial de publicaciones](https://github.com/danyneyra/garua/releases)
y ajusta la referencia a sus metadatos.

## Fuente de los datos

Cita también al **SENAMHI como fuente de los datos hidrometeorológicos**.
La referencia de Garúa reconoce el software empleado para consultarlos,
descargarlos o analizarlos.

Para facilitar la reproducción del estudio, registra:

- Nombre y código de cada estación.
- Variables utilizadas y sus unidades.
- Periodo de los datos y fecha de consulta o descarga.
- Versión de Garúa y comandos o procedimiento de análisis utilizados.
- Tratamiento de valores faltantes, trazas y otros controles de calidad aplicados.

Puedes adaptar esta descripción para la metodología de tu estudio:

> Los datos de \[variables\] de la estación \[nombre y código\], correspondientes
> al periodo \[inicio–fin\], se obtuvieron del SENAMHI mediante Garúa
> \[versión\]. La descarga se realizó el \[fecha\]. Se aplicaron los siguientes
> controles de calidad: \[descripción\].

Consulta el [portal de estaciones del SENAMHI](https://www.senamhi.gob.pe/?p=estaciones)
para identificar la fuente consultada y adapta su referencia al estilo
bibliográfico exigido por tu institución o revista.
